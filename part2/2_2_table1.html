Table 1이란?

논문의 첫 번째 표. 연구 대상의 기본 특성(baseline characteristics)을 요약합니다.

엑셀로 만들면:

  • 연속형은 median(range) 직접 계산 → 복붙
  • 범주형은 n(%) 직접 계산 → 복붙
  • p-value 따로 계산 → 복붙
  • 변수 하나 바뀌면? 처음부터 다시

R로 만들면: 코드 한 번 실행 → 끝

  • 연속형 → median (IQR) 자동 계산
  • 범주형 → n (%) 자동 계산
  • 결측치 자동 표시

그룹별 비교 + p-value

df_pt %>%
  select(Sex, Age_Tx, Primary, Multiplicity, size_cm, TD, GTV_cc, Death) %>%
  tbl_summary(
    by = Death,                          # 그룹 변수
    statistic = list(
      all_continuous() ~ "{median} ({p25}, {p75})",
      all_categorical() ~ "{n} ({p}%)"
    ),
    digits = list(
      all_continuous() ~ 1,
      all_categorical() ~ c(0, 1)
    )
  ) %>%
  add_p() %>%                            # p-value 자동 계산
  add_overall() %>%                      # Overall 컬럼 추가
  bold_labels()                          # 변수명 볼드

Tipp-value 자동 선택

add_p()는 변수 타입에 따라 알아서 검정법을 선택합니다:

  • 범주형 → chi-squared test (기대빈도 < 5이면 Fisher’s exact)
  • 연속형 → Wilcoxon rank-sum test

검정법을 직접 지정하려면:

add_p(test = list(
  all_continuous() ~ "t.test",
  all_categorical() ~ "fisher.test"
))

Note팁: label을 한 곳에서 관리하기

변수-라벨 매핑을 따로 정의해두면 여러 테이블에서 재사용 가능합니다.

my_labels <- list(
  Age_Tx        ~ "Age at treatment",
  Sex           ~ "Sex",
  Primary       ~ "Primary site",
  size_cm       ~ "Tumor size (cm)",
  TD            ~ "Total dose (cGy)",
  GTV_cc        ~ "GTV volume (cc)",
  PTVmean_BED10 ~ "PTV mean BED₁₀ (Gy)"
