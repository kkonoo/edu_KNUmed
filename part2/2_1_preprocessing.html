2-1) 데이터 읽기 & 전처리

Modified

May 13, 2026

데이터 읽기

library(tidyverse)
library(readxl)

df <- read_excel("rawdata/clinical_data.xlsx")

# 데이터 확인
dim(df)       # 76행 x 33열
glimpse(df)   # 변수 타입 한눈에
head(df)
Tipglimpse() vs str()

glimpse()는 tidyverse 버전의 str()입니다. 콘솔 너비에 맞춰 깔끔하게 보여줘서 더 편합니다.

데이터 구조 파악

이 데이터는 환자-병변(lesion) 단위입니다. 한 환자가 여러 병변을 가질 수 있어요.

# 환자 수 vs 병변 수
n_distinct(df$Key_pt)      # 환자 수
nrow(df)                    # 병변 수 (= 행 수)

# 환자당 병변 수 확인
df %>% count(Key_pt, sort = TRUE)
Warning분석 단위 주의
  • 환자 단위 분석 (OS, Death) → IN_sur == 1인 행만 사용
  • 병변 단위 분석 (LF, LFFS) → 전체 행 사용

전처리: The Tidy Way

전체 분석 시간의 70%는 전처리에 쓰인다

핵심 dplyr 함수 5개

함수 역할 SQL 대응
filter() 행 필터링 WHERE
select() 열 선택 SELECT
mutate() 새 변수 생성 AS
group_by() + summarise() 그룹별 요약 GROUP BY
arrange() 정렬 ORDER BY

filter: 행 필터링

# 환자 단위 분석용: 환자당 1행만
df_pt <- df %>% filter(IN_sur == 1)
nrow(df_pt)

# 특정 조건 필터
df_pt %>% filter(Age_Tx >= 65, Sex == "M")

# 여러 조건 조합
df_pt %>% filter(Primary == "Colon" | Primary == "Rectum")
df_pt %>% filter(Primary %in% c("Colon", "Rectum"))  # 같은 결과, 더 깔끔

select: 열 선택

# 필요한 열만
df_pt %>% select(Key_pt, Sex, Age_Tx, Primary, Death, OS)

# 특정 패턴 열 선택
df_pt %>% select(starts_with("PTV"))
df_pt %>% select(Key_pt, Sex:Age_Tx, Death:LFFS)

mutate: 새 변수 생성

df_pt <- df_pt %>%
  mutate(
    # 연령군
    Age_group = ifelse(Age_Tx >= 65, "≥65", "<65"),
    
    # factor 변환 (Table 1에서 범주형으로 인식시키기 위해)
    Sex = factor(Sex, levels = c("M", "F"), labels = c("Male", "Female")),
    Death = factor(Death, levels = c(0, 1), labels = c("Alive", "Dead")),
    
    # 연속형 변수 단위 변환
    size_cm = size_mm / 10,
    
    # BED10 카테고리
    BED_group = case_when(
      PTVmean_BED10 >= 100 ~ "≥100 Gy",
      PTVmean_BED10 >= 80  ~ "80-99 Gy",
      TRUE                  ~ "<80 Gy"
    )
  )
Tipifelse() vs case_when()
  • 조건이 2개 → ifelse()
  • 조건이 3개 이상 → case_when()

group_by + summarise: 그룹별 요약

# Primary별 환자 수, 중앙 나이
df_pt %>%
  group_by(Primary) %>%
  summarise(
    n = n(),
    median_age = median(Age_Tx),
    death_rate = mean(Death == "Dead")
  ) %>%
  arrange(desc(n))

전처리 파이프라인 완성

위 과정을 하나의 스크립트로 정리하면:

# ===== 파라미터 =====
DATA_FILE <- "rawdata/clinical_data.xlsx"
# ====================

library(tidyverse)
library(readxl)

# 1. 읽기
raw <- read_excel(DATA_FILE)

# 2. 환자 단위 데이터
df_pt <- raw %>%
  filter(IN_sur == 1) %>%
  mutate(
    Age_group = ifelse(Age_Tx >= 65, "≥65", "<65"),
    Sex = factor(Sex, levels = c("M", "F"), labels = c("Male", "Female")),
    Multiplicity = factor(Multiplicity),
    size_cm = size_mm / 10,
    BED_group = case_when(
      PTVmean_BED10 >= 100 ~ "≥100 Gy",
      PTVmean_BED10 >= 80  ~ "80-99 Gy",
      TRUE                  ~ "<80 Gy"
    )
  )

# 3. 병변 단위 데이터
df_lesion <- raw %>%
  mutate(
    size_cm = size_mm / 10,
    LF = as.numeric(LF)
  )

# 4. 저장
saveRDS(df_pt, "analysis/df_pt.rds")
saveRDS(df_lesion, "analysis/df_lesion.rds")
Note왜 .rds로 저장하나?
  • factor level, 변수 타입이 그대로 보존됨
  • csv로 저장하면 factor가 다시 문자열로 돌아감
  • 다음 스크립트에서 readRDS()로 바로 불러오면 전처리 반복 불필요
