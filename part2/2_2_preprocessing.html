왜 전처리를 스크립트로 만드나?

전체 분석의 80%: 전처리..😂

앞에서 Table 1을 만들면서 데이터를 읽고, 필터링하고, 변수를 변환하는 과정을 거쳤습니다. 이 과정을 재사용 가능한 스크립트로 정리하면:

  • 데이터가 업데이트되면 스크립트만 다시 실행
  • 다음 분석(생존분석, plot 등)에서 전처리된 .rds를 바로 로드
  • 리뷰어 코멘트 대응 시 한 줄만 수정

mutate: 새 변수 생성

df_pt <- df_pt %>%
  mutate(
    # 연령군
    Age_group = ifelse(Age_Tx >= AGE_CUT, "≥65", "<65"),
    
    # factor 변환
    Sex = factor(Sex, levels = c("M", "F"), labels = c("Male", "Female")),
    Death = as.numeric(Death),  # Surv()에서 쓰려면 numeric 유지
    Death_f = factor(Death, levels = c(0, 1), labels = c("Alive", "Dead")),  # Table 1용
    
    # 연속형 변수 단위 변환
    size_cm = size_mm / 10,
    
    # BED10 카테고리
    BED_group = case_when(
      PTVmean_BED10 >= 100 ~ "≥100 Gy",
      PTVmean_BED10 >= 80  ~ "80-99 Gy",
      TRUE                  ~ "<80 Gy"
    )
  )
Tipifelse() vs case_when()
  • 조건이 2개 → ifelse()
  • 조건이 3개 이상 → case_when()

Note왜 .rds로 저장하나?
  • factor level, 변수 타입이 그대로 보존됨
  • csv로 저장하면 factor가 다시 문자열로 돌아감
  • 다음 스크립트에서 readRDS()로 바로 불러오면 전처리 반복 불필요

④ Rscript 완성본

위 과정을 .R 파일 하나로 정리하면, 터미널에서 바로 실행할 수 있습니다.

# ===== 02_preprocessing.R =====

# ----- 디렉토리 & 파라미터 -----
indir  <- "analysis/"
outdir <- "analysis/"
AGE_CUT <- 65

library(tidyverse)

# 1. 데이터 로드 (2_1에서 저장한 rds)
df_pt <- readRDS(paste0(indir, "1_df_pt.rds"))

# 2. 전처리
df_pt <- df_pt %>%
  mutate(
    Age_group = ifelse(Age_Tx >= AGE_CUT, "≥65", "<65"),
    Sex = factor(Sex, levels = c("M", "F"), labels = c("Male", "Female")),
    Death = as.numeric(Death),
    Death_f = factor(Death, levels = c(0, 1), labels = c("Alive", "Dead")),
    Multiplicity = factor(Multiplicity),
    size_cm = size_mm / 10,
    BED_group = case_when(
      PTVmean_BED10 >= 100 ~ "≥100 Gy",
      PTVmean_BED10 >= 80  ~ "80-99 Gy",
      TRUE                  ~ "<80 Gy"
    )
  )

# 3. 저장
saveRDS(df_pt, paste0(outdir, "2_df_pt_processed.rds"))

cat("✅ Preprocessing done:", nrow(df_pt), "patients\n")
# 터미널에서 실행
