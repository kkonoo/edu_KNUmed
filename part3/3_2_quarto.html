3-2) Quarto로 원클릭 리포트 만들기

Modified

May 13, 2026

왜 Quarto인가?

지금까지 한 작업:

R script → 표 (docx) + 그래프 (tiff) → Word에 복붙 → PI에게 전달

Quarto를 쓰면:

Quarto 문서 하나 → Render 클릭 → 코드 + 결과 + 해석이 포함된 보고서 완성
Tip사실 지금 보고 있는 이 자료가 Quarto입니다

이 강의 웹사이트 자체가 .qmd 파일로 만들어졌습니다. 코드, 결과, 설명이 한 파일에 들어있어요.

Quarto 문서 기본 구조

---
title: "SBRT 올리고전이 생존분석 보고서"
author: "하은지"
date: today
format: html
---

## 연구 배경

올리고전이 환자에서 SBRT의 치료 성적을 분석하였다.

## 분석 결과

​```{r}
library(gtsummary)
df_pt %>%
  select(Sex, Age_Tx, Primary, Death) %>%
  tbl_summary(by = Death)
​```

위 Table 1에서 두 군 간 유의한 차이는 없었다.

핵심: 코드와 해석이 같은 문서에 있으므로 결과가 바뀌면 해석도 바로 확인/수정 가능

출력 포맷

YAML에서 format만 바꾸면 됩니다:

format 출력 용도
format: html 웹 페이지 내부 공유, 빠른 확인
format: docx Word 문서 PI 보고, 논문 초고
format: pdf PDF 공식 보고서 
# Word 출력
format:
  docx:
    reference-doc: template.docx   # 서식 템플릿 지정 가능

# PDF 출력 (한글 지원)
format:
  pdf:
    documentclass: article
    mainfont: "Malgun Gothic"

인라인 코드: 숫자 직접 타이핑 금지

논문 본문에 숫자를 넣을 때:

나쁜 방법: “총 45명의 환자가 포함되었다” (직접 타이핑)

좋은 방법:

총 `​r nrow(df_pt)`명의 환자가 포함되었다.
중앙 추적 기간은 `​r round(median(df_pt$OS), 1)`개월이었다.

→ 데이터가 바뀌어도 숫자가 자동 업데이트됨

Warning이게 왜 중요한가

리뷰어: “inclusion criteria를 바꿔서 재분석해주세요”

  • Word: 본문의 모든 숫자를 하나하나 찾아서 수정
  • Quarto: 데이터만 바꾸고 Render → 본문 숫자 자동 변경

실전 템플릿: 분석 보고서

# ===== 파라미터 =====
DATA_FILE <- "rawdata/clinical_data.xlsx"
# ====================

library(tidyverse)
library(readxl)
library(gtsummary)
library(survival)
library(survminer)
library(broom)

df_pt <- read_excel(DATA_FILE) %>%
  filter(IN_sur == 1) %>%
  mutate(
    Death = as.numeric(Death),
    Sex = factor(Sex),
    Multiplicity = factor(Multiplicity)
  )
# Table 1
df_pt %>%
  select(Sex, Age_Tx, Primary, Multiplicity, size_cm, TD, Death) %>%
  tbl_summary(by = Death) %>%
  add_p() %>%
  add_overall()
# KM curve
fit <- survfit(Surv(OS, Death) ~ Multiplicity, data = df_pt)
ggsurvplot(fit, data = df_pt, pval = TRUE, risk.table = TRUE)
# Cox regression
cox <- coxph(Surv(OS, Death) ~ Age_Tx + Sex + Multiplicity + size_cm, data = df_pt)
tidy(cox, conf.int = TRUE, exponentiate = TRUE) %>%
  select(term, estimate, conf.low, conf.high, p.value)

이 템플릿을 .qmd로 저장 → Render → 보고서 완성

정리

✅ Quarto = 코드 + 결과 + 해석을 한 문서에
✅ format만 바꾸면 html / docx / pdf 출력
✅ 인라인 코드로 숫자 자동 업데이트
✅ 데이터 변경 → Render 한 번 → 보고서 전체 갱신
